## Итог

Дерево статуса, исполнителя и `milestone` совпало с выборкой и со строками `twin_link`. Задача без связи остаётся в группе `type: TWIN`, `value: null`. Несколько концов одной связи кладут задачу в несколько узлов и увеличивают сумму `count`. `workType` — `DATA_LIST_OPTION`. Тип `LINK` в запросе отвергается.

Три расхождения с текстом изменений. Пустой ключ при `COUNT_DESC` не последний. Десятичный ноль по-прежнему три группы. Timestamp сдвинут на пояс JVM.

## Расхождения

### Пустой ключ не последний при сортировке по размеру

Текст: пустой ключ последний при любой сортировке. `COUNT_DESC` по исполнителю вернул 63 группы. Первая — 501 задача. Группа `"value": null` (87 задач) стоит второй, не последней. При `NAME_ASC` и `KEY_ASC` пустой ключ последний: это проверено на исполнителе и на `milestone`.

### Decimal

`TASK.progress` даёт 20 групп. Три из них — ноль разных масштабов, после разбора JSON все с ключом `0`, размеры 668, 123 и 40.

### Timestamp

`OBJECT_EXT.startDate`: в базе `2026-01-01 00:00:00`, в ответе `"2025-12-31T21:00:00.000Z"`, `type: TIMESTAMP`.
